# 番茄任务管理系统（控制台版）

一个基于 **纯 Java 11 + JDBC + SQL Server** 的多用户任务管理与番茄计时系统，控制台菜单交互，不依赖任何框架。

---

## 一、项目简介

- **题目**：番茄任务管理系统（控制台版）
- **定位**：多用户任务管理 + 番茄计时 + 专注记录 + 统计查询
- **界面**：控制台菜单（CMD 模式），不使用 Swing / JavaFX
- **数据库**：SQL Server
- **技术栈**：纯 Java + JDBC，不使用任何框架（Spring、SSH 等）

### 核心功能

1. **用户模块**：注册、登录（SHA-256 密码哈希）、数据按用户隔离
2. **任务模块**：新增、修改、逻辑删除、标记完成、任务列表
3. **任务类型**：按次数重复（REPEAT_COUNT）、按日期重复（REPEAT_DATE）
4. **番茄计时**：倒计时 / 正计时，支持开始、暂停、放弃、完成
5. **番茄记录**：每次专注写一条记录（FINISHED / ABANDONED）
6. **每日记录**：REPEAT_DATE 任务每天生成一条记录，逾期自动写库
7. **记录查询**：按日期、任务、标签查询番茄记录，查询未完成任务与未完成天数
8. **统计分析**：总/本周完成次数、总/本周专注时长、未完成次数
9. **备份恢复**：序列化保存与恢复用户任务、番茄记录、每日记录
